# Clinical Assistant

Cleaned Next.js + Supabase + Gemini source extracted from the current working project.

## Important
- This repository intentionally excludes `.next`, `node_modules`, `.env.local`, duplicate project folders, and large seed SQL files.
- The Supabase database is already populated in the development project; `supabase/001_schema.sql` is retained for schema reference.
- Create `.env.local` in the project root with the Supabase and Gemini environment variables.

## Run
npm install
npm run dev

## Validate
npm run build
